# Security reports

Use GitHub's private vulnerability reporting when available. Otherwise open an issue describing the impact without credentials, private form links, response data or file paths, and request a private channel before sharing sensitive details.

Use the current GitHub build for unreleased fixes. Saved responses and run logs contain plaintext answers; keep them in a private directory. Do not commit cookies, browser profiles, credentials or real response data.

AI generation sends form context and reference examples to ChatGPT. Known secret URL parameters are redacted in outgoing requests, including retries; embedded credentials and account/edit-response links are omitted. This is not a general secret detector. Local configurations and AI checkpoints retain original metadata and supplied answers in plaintext so saved identities and recovery remain intact. Private browser mode does not encrypt these files.

The Windows wheel vendors selected upstream Selenium files. Updates must verify the pinned recipe, upstream advisories, preserved notices, installed-wheel checks and browser tests; dependency alerts do not update that bundled runtime automatically.
