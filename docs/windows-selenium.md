# Windows Selenium runtime

This runtime is used only by ChatGPT generation and visible form review. Automatic form submission uses direct HTTP and does not start Selenium or a browser.

Windows x64 wheels include a private, hash-locked subset of Selenium 4.51.0. Portable wheels retain official Selenium. The subset keeps Chrome, Edge, Firefox, waits, native controls, exceptions, scripts, certificates, proxies and the unmodified Windows Selenium Manager. It removes other OS binaries, unsupported browser adapters, generated DevTools code and the unused BiDi/CDP connection feature. Trio, WebSocket and their unused dependencies are not installed.

This is GFormBot's internal runtime, not a replacement for Selenium's public API. It never installs into the `selenium` namespace. Small synchronous helpers required by upstream imports/initialization remain; further method-by-method rewriting would save little and increase maintenance risk. Upstream license headers, LICENSE, NOTICE and Manager third-party notices are retained.

Python 3.11+ uses its standard-library `Self` type; only Python 3.10 needs `typing_extensions`.

Fresh Windows x64 / Python 3.12 measurements against the previous code with official Selenium 4.51.0:

| Measurement | Before | Subset |
| --- | ---: | ---: |
| Complete runtime downloads | 16.35 MB | 5.39 MB |
| Installed runtime files, excluding bytecode | 44.97 MB | 17.50 MB |
| Additional generated bytecode | 22.18 MB | 11.83 MB |
| Runtime distributions | 28 | 14 |
| Browser-runtime imports, median | 0.762 s | 0.496 s |
| Python peak RSS for the import probe | 36.43 MB | 32.35 MB |
| Chrome workload including startup/cleanup | 5.24 s | 5.10 s |
| Edge workload including startup/cleanup | 5.60 s | 5.44 s |

Decimal MB; Windows x64, Python 3.12.10, nine alternating import samples and five alternating browser samples per runtime. Python, installed browsers and downloaded drivers/caches are excluded from installation sizes. Upgrades may retain shared dependencies. Startup/RSS measurements use fresh Python processes with warm OS caches; browser work uses local HTTP pages and warm driver caches. Browser timings overlap normal variation; import improvements do not imply the same improvement in form-filling speed or browser memory.

Cold Chrome driver setup succeeded for both runtimes in about 8.3 seconds and produced the same 24.63 MB driver cache. Clean install, upgrade, simultaneous official/private sessions, uninstall isolation, offline failure, TLS/proxy handling and identical wheel rebuilds were checked. Browser fixtures cover the existing fill, routing, review, recovery and follow-up paths without live Google submissions.

## Rebuild and check

```bash
python tools/vendor_selenium.py --check
python tools/vendor_selenium.py --wheel path/to/selenium-4.51.0-py3-none-any.whl
python -m build
python tools/check_wheel.py dist
```

The recipe checks the upstream wheel SHA-256 before selecting the import closure, applying narrow namespace/protocol patches and recording every output hash. Review the recipe when changing upstream versions; do not hand-edit generated files. The source archive includes the subset, so installing from it needs no separate Selenium-source download. Windows wheel tags restrict this bundle to x64; other Windows architectures use the portable dependency path.

To compare two clean environments built with the same Python and dependency versions:

```bash
python tools/benchmark_selenium.py --python BEFORE_PYTHON --compare-python AFTER_PYTHON --output comparison.json
```

`GFORMBOT_BUILD_FULL_SELENIUM=1` builds the portable variant on Windows for compatibility checks. No build command publishes packages.
